# 🌤️ Full-Stack Weather & Task Application

A modern, full-stack web application built from scratch that combines real-time weather tracking with a built-in daily task manager.

## 🚀 Features
* **Real-Time Weather:** Fetches live weather data, temperature, humidity, and wind speed for any city worldwide using the OpenWeatherMap API.
* **Daily Task Manager:** Integrated to-do list to keep track of daily goals and tasks right alongside your weather dashboard.
* **Full-Stack Architecture:** Powered by a React frontend and an Express backend, communicating seamlessly via Axios and CORS.

## 🛠️ Tech Stack
* **Frontend:** React, Vite, Axios, CSS
* **Backend:** Node.js, Express, dotenv, CORS
* **API:** OpenWeatherMap API
